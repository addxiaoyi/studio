# 节点拖动与保存冲突修复

用户截图同时出现旧版网页嵌入节点、另一工作流的侧栏、本机恢复草稿和画布版本冲突。排查确认：选中和缩放触发整画布保存，多个标签制造版本竞争；临时busy/saving锁被写进节点；跨工作流拖动后没有切换所属流程并保留新位置。

修复内容：

- 仅实际内容或背景/网格变化触发保存，选择、平移、缩放、节点进度和临时锁不写库。
- 临时锁不再保存，打开旧画布时清除遗留锁；真正运行中的流程仍由当前执行状态锁定。
- 跨流程拖动结束后切换到节点所属流程并采用新位置；已保存参数仍以工作流文档为准。当前草稿未保存时继续提供保留或保存切换选项。
- 打开页面不再单独发起归一化保存，避免与正常保存队列竞争。
- 上次未保存的恢复副本在选择恢复前保留，正常浏览不会清除或覆盖。与服务器完全相同的卸载副本不再误报恢复；不同内容或文件仍保留。新增“下载本机副本”便于独立保全。
- 顶栏空白透明区域不再遮住保存/恢复按钮。冲突后停止无效重复保存，但继续保留同一页面的新编辑；CAS版本冲突仍不自动覆盖远端。
