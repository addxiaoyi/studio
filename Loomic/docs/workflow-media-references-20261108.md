# 画布素材嵌入工作流

画布中的已保存图片和视频可拖到生成节点，松开时显示GSAP嵌入反馈。图片沿真实素材输入连线提供给模型；视频自动建立“原视频 → 可配置时刻的抽帧 → 生成”链路，抽帧由现有FFmpeg执行器完成。原素材保留原位。

节点显示引用缩略图，左侧节点设置可选择画布素材、预览原视频、修改取帧时刻、移除引用和撤销。引用与参数随工作流草稿保存，刷新可以恢复。重复拖入同一素材不会产生重复输入，每个生成节点最多6张参考图；视频抽帧占一个名额。已关联其他工作流的原素材需要先解除旧输入绑定，防止改写另一组工作流的画布关联。

## 执行与费用

- 拖入、移除、保存不会执行或扣费。抽帧仍需动作确认；每次模型生成独立显示模型、实际输入、参数及报价，不受自动批准设置影响。
- 参考图在报价前、确认时和模型提交前重新校验所有者、工作区、原画布元素、删除状态和保留期。视频没有完成抽帧或上游缺少回执时停止，不静默丢弃参考输入。
- 报价卡可预览此次实际送入模型的图片，包括已完成的视频抽帧。选择模型时过滤明确不支持参考图的选项；用户手选模型不静默切换。
- 生成使用现有扣费、后台任务、Provider回执、私有资产和画布/聊天结果交付。断线恢复读取原任务，避免重复调用与重复扣费。
- 若worker在扣费回执已写入、HTTP尚未关联报价的间隙领取任务，仅在用户、工作区、幂等键、完整payload和费用回执全部匹配时补全关联；没有费用回执不允许调用模型。

## 实际验证

- Web素材绑定与原画布场景12项通过：真实输入命令、引用去重、原素材保留、视频抽帧适配、数量限制、解绑与共享输入保留。
- Server审批和生成16项通过；HTTP费用接口与媒体执行器相关25项通过。
- 隔离PostgreSQL工作流12项通过，覆盖报价后删除、到期、未扣费不执行、扣费回执关联恢复与重复确认不新增账本记录。
- 实际FFmpeg生成两段视频、顺序合成并从指定时刻提取PNG；检查解码后的像素颜色及越界拒绝，1项通过。
- Chromium执行真实图片与MP4拖放、节点预览、取帧时间修改、保存刷新、移除撤销及窄屏测试，1条通过。Windows 0.2.21隔离用户目录中包含前述流程的5条端到端全部通过（1.7分钟）；这验证了候选客户端运行新版Web，不代表发布了新的安装包。
- Web、Server和生产兼容Server类型检查通过，生产静态构建成功。日志位于 `M:/loomic-builds/workflow-materials-desktop.log`、`workflow-materials-web-build.log`、`workflow-materials-production-types.log`。

测试发现小视频悬浮操作条挡住原生拖动，已移到视频外侧；底部画布工具栏避让左侧工作流面板。减少动态效果偏好下保持相同的绑定和保存逻辑。
