# Web 与桌面端的界面层级和恢复路径

使用真实线上工作台、素材和市场页面确定问题，修改两端共用的前端组件；没有运行付费生成或变更用户现有项目。本轮覆盖共享导航、页面切换、通知、弹窗、下拉选择，以及工作台、素材、任务历史、桌面设置与本地开发工作台。未把这些检查等同于所有业务页面的全部状态都已验收。

## 改动

- 创作输入与画布、视频、女装、素材四个入口进入工作台首屏；统计移到最近项目之后，价格及趋势折叠展示，去掉重复项目栏。修正新建项目文字对比度、中文操作与示例分类。
- 去掉全站高密度背景噪点；页面切换采用 GSAP 透明度动画并尊重减少动态效果设置，不再使用影响固定面板定位的 filter/transform。工作台自身不再分批淡入内容。
- 共享弹窗增加视口高度、滚动、窄屏按钮和标题栏避让；关闭按钮汉化。下拉层在弹窗之上并限制视口边距。保留 Base UI 的键盘、焦点圈定、Escape 及返回触发器。
- Web 与桌面通知：错误保持直到关闭，普通通知阅读时暂停计时，最多4条，长文字换行；桌面错误使用 alert。消除无人管理的超时回调。
- 登录状态未知时显示可重连状态，不当成退出登录；区域错误的返回入口指向真正的 Web/桌面工作台。全局复制错误失败提供明确反馈。
- Web 侧栏可固定展开、保存偏好。桌面路由正确高亮、自动展开当前进阶项，补市场/历史入口，设置进入桌面设置；退出视频页使用完整导航以释放运行时。极窄窗口收拢标题栏导航，保留窗口控制和快捷查找。
- 素材检索忽略过期请求，旧响应不能覆盖新搜索；恢复按钮防重复操作，恢复/移入恢复区后的反馈不再错误指向作品库。
- 任务历史支持状态中文、目标搜索、状态筛选与清除，刷新失败保留旧记录，阻止重叠刷新及账号切换后的旧响应。
- 桌面权限读取失败可重新检查；本地开发工作台修复文件读取竞态、停止失败无反馈，以及保存期间继续编辑被错误标为已保存的问题。
