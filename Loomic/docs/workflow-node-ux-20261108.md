# 节点交互改造

本轮围绕现有画布工作流实现交互修复，不引入外部扣子账号或新的执行服务。

## 已确认的问题与处理

1. 原节点借用网页嵌入元素，选中时暴露链接工具条和外链图标。现在使用原生画布形状承载节点，内容由同一坐标系中的控件层显示；普通网页嵌入、视频与文稿仍走原路径。旧节点按原ID升级，保留位置、参数、素材和连线。
2. 拖动或框选节点会展开设置并改变视野。现在拖动只改变位置，单击打开设置；列表选中不强制缩放，显式“定位”才移动视野。双击、Enter和F2打开节点编辑，不在节点内误建普通文本。
3. 连接点只作装饰。现在可拖出连线，也可键盘或点击先选输出再选输入，兼容目标高亮，不兼容输入说明原因，Esc取消。保留原箭头工具和设置中的上游选择。
4. 曲线难命中。增加独立命中区，选中显示上下游名称与“断开”。Delete和原生撤销仍然有效；在设置内断开后保持当前节点，便于马上重连。
5. 参数排在长节点列表下方。选中后显示紧凑节点切换条、全部节点入口与明确的定位按钮，并自动滚动到参数。窄屏编辑时给设置更多高度，保持右侧AI对话的既有布局规则。
6. 新增节点缺乏上下文。节点旁的“＋”提供分类、搜索和说明，接在选中节点之后并避让现有素材，兼容输入自动连接；取消不修改流程。
7. 保存和运行状态不明确。有效草稿提供“保存并运行”，保存失败保留修改且不进入运行确认；运行仍需要确认，付费生成继续逐次审批。支持Ctrl/Cmd+S保存。
8. 切换流程时未保存修改容易卡住或被覆盖。现在提供保存并切换、保留本机草稿并切换、继续编辑；有恢复草稿时阻止投影覆盖和继续编辑，先选择恢复或服务器版本。保存期间发生的新编辑继续保留为本机草稿。
9. 节点对象字段顺序变化被误判为编辑，导致撤销偶发需要两次。比较时统一字段顺序、过滤无实际变化的同步，仍保留合成输入的真实顺序。
