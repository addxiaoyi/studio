# 工作流运行前检查（HS-023）

在已有 IF / Switch 样本演算之后，补齐运行前的结构、素材、固定结果、媒体生成模型和价格检查。代码仍在 `codex/agent-workspace-ci` 的本地工作区。

点击“运行流程”或执行到指定节点后，确认弹窗先读取问题清单。检查中、服务错误或存在阻断项时不能确认运行。每项显示节点、原因和修复动作，点击后返回对应节点设置。合法的不完整草稿也能打开检查，不会因缺少编译结果而隐藏入口。

检查不保存草稿、不创建目标、审批或生成任务，也不修改供应商健康状态。确认运行才先保存当前草稿，再启动对应版本。切换流程、版本、执行目标或图内容会使旧检查失效；迟到的响应不能覆盖当前结果。画布保存期间发生变化时要求重新检查。

## 服务端

新增 `POST /api/canvases/:canvasId/workflows/:id/preflight`，请求为 `{ revision, graph?, targetNodeId? }`。检查所属画布权限、流程所有者和版本，返回 `{ revision, ready, issues, quotes }`，沿用 `{ ok, data?, error? }` 响应封装。无登录为 401，版本冲突为 409；检查基础设施故障记录服务端错误并返回 503。

问题覆盖：参数/连线及执行编译、私有素材绑定与保留期限、固定结果指纹与权限、媒体模型可用性及输入能力/视频时长、固定价格可计算性。仅检查本次执行范围，并排除固定结果已经替代的上游。相同节点的相同问题去重。

媒体模型使用执行器相同的模型选择和费用规则，以只读方式读取。保留合法的零费用生成；按实际 token 用量计费、无法保证流程预算的媒体模型会被阻断。费用是当前参数下的节点参考值，实际生成仍逐次审批，累计预算门禁保持执行。

运行接口再次检查保存版本，防止直接调用接口或检查后模型停用、素材失效。重复运行请求仍按原幂等键返回既有回执。AI 发起的工作流运行同样经过该服务。
