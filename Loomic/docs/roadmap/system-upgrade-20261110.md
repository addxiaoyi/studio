# Helstera 全局升级目标

目标保持用户指定的九个方向，分阶段实施；阶段完成不代表全部目标完成。基线提交 `91dcf07`，既有 0.2.30 功能和用户资料保留，付费模型调用继续逐次确认。

## 1. 生产稳定性与容量治理（进行中）

要求：依赖就绪后切换流量；旧进程停止接收新任务并完成或保存已有工作；临时空间预留、跨进程并发限额；保护当前更新通道和必需历史安装器的保留策略。

证据：实时磁盘/进程/代理配置；断依赖时 readiness 503；切换期间连续认证/API/WebSocket 探测；进程退出与重启恢复；不足空间和并发竞争回归；保留清单、释放字节及下载哈希。

## 2. 统一工程中心

要求：工程统一关联画布、流程、时间线、对话、素材、版本；视图切换使用同一工程身份；刷新和换设备后恢复当前工作及下一步。

证据：项目数据契约/迁移；页面切换、断线刷新、两个独立设备身份的端到端回归；禁止串工程/串账户。

已核对的起点（2026-11-10）：

- `apps/server/src/local-db/schema.sql` 已有 projects→canvases→chat_sessions 关联，工作流和媒体时间线复用画布内容；继续沿用这些身份，避免再造第二套工程。
- `apps/web/src/lib/studio-project-key.ts` 的视频入口目前兼容画布参数和会话内记忆，默认仍落在用户草稿。`scripts/visualforge/entry.tsx` 将工程写入 IndexedDB；AI 方案和视频对话也按 projectKey 本机存储，不能误称已有跨设备编辑恢复。
- `StudioRuntime.projectId()` 实际返回合成 ID，区别于数据库工程 UUID。新契约需显式区分 projectId、canvasId、compositionId，并保留旧入口兼容。
- 下一步先做带权限验证的工程上下文与版本契约，再接视频文档、视图导航和同步冲突；媒体字节默认留在用户本机，云端仅保存用户选定的描述/预览/原片。旧本机草稿不能被默默归入任意工程。
- 跨设备素材缺失应显示重新关联/取回入口，不能用空白工程覆盖已有编辑；跨账户、跨工程、并发修改和归档权限是必需回归。
- 候选实现：工程上下文 API/迁移、统一视图导航、旧画布视频/对话草稿保留迁移、第二设备缺少视频副本提示已通过本地数据库与真实浏览器回归，详见 `../audit/project-context-20261110.md`。尚未完成视频文档同步、跨设备取回及生产发布，不能把导航基础等同于统一工程完成。
- 2026-11-11 候选继续：新增用户确认后的工程描述版本同步、素材摘要/重新关联、第二浏览器恢复并实际编辑，以及保留和恢复本机修改副本。原片默认不上传；分块哈希覆盖大于 64 MiB 素材。详见 `../audit/project-video-sync-20261111.md`。本地用户文件夹工程、超 250 MiB 云端取回、跨设备视频 AI 对话与生产发布仍待完成。

## 3. 媒体处理引擎

要求：代理视频、按需解码、缩略图/波形预计算、增量编译、预览优先调度；桌面本地执行，导出读取原片。

证据：优化前后同样素材基线；10–30 分钟 4K、低内存、边播放边处理；成片时长、音轨、画面、取消恢复及峰值资源。

## 4. 完整本地工程

要求：离线打开/编辑/恢复；用户选择同步工程描述、预览或原片；跨设备冲突、外置盘稳定身份、素材版本；共享素材独立副本。

证据：断网修改和重启；冲突解决不丢版本；跨盘/盘符变化；独立副本编辑不影响其他引用；服务端字节不随纯本地工作增长。

## 5. 统一 Agent 执行中心

要求：目标、计划、审批、执行、产物、恢复共用记录；局部重做、复用已验证结果、接管后继续；无真实产物不得显示交付成功。

证据：网站到成片、试穿到视频、脚本到多尺寸交付的任务链；回执丢失、重复确认、重启、权限变化和部分失败回归。

## 6. 结算闭环

要求：供应商实际用量/费用核验、在途取消、未知结果待核验、最终退款、账单凭证；固定价和按量计费分别处理。

证据：真实供应商能力与回执；数据库并发和幂等对账；取消失败/超时不虚假退款；逐次费用审批仍有效。付费验证须用户明确授权。

## 7. 全站交互规范

要求：选择/拖拽/双击设置/菜单/浮层/快捷键/撤销，以及保存、同步、生成、导出状态在各运行时一致。

证据：共享交互契约与组件；深浅主题、窄屏、200% 缩放、键盘和焦点、减少动态效果、多个浮层及错误状态验收。

## 8. 三条完整创作场景

网站介绍：登录体验→录制→字幕配音→剪辑→成片。

商品展示：人物/服装→试穿→批量变体→商品视频。

内容生产：选题→脚本→分镜→生成→多尺寸交付。

每条必须提供输入、费用范围、输出规格、失败恢复和可播放/可下载的真实产物；测量首个作品完成路径。

## 9. 模块、质量评测和诊断

要求：按职责拆分桌面/Agent 大模块；贯穿页面、任务、供应商、产物的诊断编号；分别维护界面、真实模型质量、长片压力、安装升级证据。

证据：接口契约与回归不变；故障可由编号追踪；真实样本衡量成片质量、人物服装保真与返工量；不将注入响应记为真实模型验收。
