# 网站录制、画布与 AI 剪辑

任务卡的介绍原来以纯文本显示 Markdown，录制结果只进入素材库与聊天。现在复用聊天 Markdown 渲染器；完成任务后通过关联会话定位画布，原子写入截图与视频，返回可重试的交付回执。并发与刷新不会重复添加，已删除的画布素材不会被自动补回。所有素材查询同时检查任务、创建者、工作区、保留期与删除状态。

画布视频的操作栏位于 Excalidraw 绘图层上方，悬浮或选中时可加入时间线、进入 AI 剪辑。导航前等待画布保存，保留素材ID与裁剪范围；视频工作区在用户点击后加入实际剪辑时间线，并填入对话草稿，沿用原有计划预览和逐项审批。

录制逐帧采集改用有超时的 Chromium 截图会话，仍由 GSAP 推进每个帧位置。已就绪应用不再等待后台轮询停止；回归中旧实现额外等待8527毫秒，新用例全程约1578毫秒。任务进度展示已生成秒数及剩余时间估算；未完成页面列出原因，重试只准备该页的新审批。
