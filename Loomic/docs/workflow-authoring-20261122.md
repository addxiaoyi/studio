# 工作流字段选择、逐项 AI 修改与编剧连接检查

本轮沿 `codex/agent-workspace-ci` 完成 HS-021、HS-027，以及编剧连接的运行前检查。连同此前本地完成的 HS-022 样本演算和 HS-023 运行前问题汇总一起提交。

## 上游字段选择（HS-021）

IF、Switch、字段提取和列表拆分支持从上游样本选择字段，显示实际类型和值。当前 JSON/文字输入直接读取已填写的内容；其他节点只使用匹配当前配置及上游依赖的成功回执。修改下游不丢失仍有效的来源样本，修改来源或祖先则使旧样本失效。

IF / Switch 使用完整输出路径，例如 `json.score`；提取和 JSON 列表拆分使用执行器对应的 JSON 范围，例如 `person.name`。批量操作的提取字段只展示上游列表首项的实际内容，不把整个列表的路径误当成单项路径。

支持字段筛选、手填路径、缺失字段提示和定位来源节点。没有成功样本时明确说明。只枚举安全的自有字段，跳过原型属性和无法用点路径表达的字面字段名，限制深度及条数，避免大样本拖慢界面。下拉框的未选状态使用真正的空值，支持键盘选择。

## 逐项接受 AI 修改（HS-027）

按节点新增、更新、删除，连线新增、修改、断开，以及输入顺序和流程元信息列出改动。支持全选和清空，再选择要接受的部分。新增节点和连线所需的依赖自动纳入选择；依赖项在清单里标明，取消依赖也取消相关选择。

未选节点、参数、流程名称和连线保留原版本。删除节点单独确认，并处理相关连线和分组成员；不删除原始素材文件。合成等节点的输入顺序按明确选择处理。重复或伪造的改动标识、无法保持合法连线的选择会被拒绝。

服务端从已保存的提议快照重新计算选择，不接受客户端任意改写后的图。沿用所有者、成员资格和版本检查。已应用的提议保存所选改动标识；重复相同请求不再保存新版本，改用其他选择重试会返回冲突。刷新后展示实际接受的选择和数量。

仅更新草稿，运行仍需确认并通过运行前检查。部分修改可以保留尚待填写参数的草稿；运行前汇总继续阻断缺少输入、模型或素材的流程。

## 编剧连接检查

使用执行时相同的工作区编剧配置，检查凭据和接口连通性。OpenAI 兼容接口读取 `/models`；Google API 读取模型元数据；Vertex 使用 ADC 读取发布模型元数据，并带上所配置项目的配额请求头。

多个编剧节点在一次检查中共用连接检查结果，问题分别定位到对应节点。运行接口重新检查，实际编剧执行前再检查。凭据缺失、认证拒绝、限流、服务失败或超时会阻止启动或推理，不发送创作提示词进行探测。

Vertex 元数据资源路径按 [Google 官方 Discovery 文档](https://aiplatform.googleapis.com/$discovery/rest?version=v1) 核对，为 `publishers/{publisher}/models/{publisher_model}`，不复用包含项目/区域的推理路径。Google API 模型元数据路径参考 [官方模型 API](https://aistudio.google.com/api-reference/models)。SDK 调用同时核对了本地安装的 `google-auth-library` 类型和文档。

这些检查验证配置、认证和元数据接口，不能替代真实推理回执。没有使用生产凭据进行收费推理；浏览器编剧执行使用隔离测试编剧，连接检查则经过真实本地 HTTP 元数据接口。
