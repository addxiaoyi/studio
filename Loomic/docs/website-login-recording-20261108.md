# 登录后网站体验与录制

入口：Agent 浏览器侧栏 → 网站介绍演示与录制 → 需要登录后体验。填写体验页面、HTTPS 登录地址、账号密码和仅在登录后出现的文字，查看并确认方案后执行。可选多光标介绍演示或真实浏览录屏；后者读取最多 3 个同站页面并滚动。结果沿用素材库、原聊天回写与刷新恢复。

登录流程使用独立的未录制上下文，确认登录成功后才把 Cookie、localStorage 和 sessionStorage 转移到录制上下文，任务完成后关闭整个临时浏览器。密码不会进入聊天、模型参数、任务 JSON、浏览器恢复存储或结果。AES-GCM 密文使用用户与工作区身份作为附加认证数据；15 分钟失效，执行前原子消费并清空密文，取消/拒绝时清空，过期清理由每分钟任务处理。服务端复用既有加密配置，也支持独立 WEBSITE_LOGIN_ENCRYPTION_KEY。

审批绑定目标网址、登录网址、成功标记、可选控件选择器、一次性凭据引用及录制参数。登录只允许向确认的同源 HTTPS 站点发送一次携带凭据的 POST；完成后恢复只读请求门禁。跨站导航、内网地址、业务 POST、支付及已识别的退出/删除链接被拦截；连接器撤销与任务取消在网络执行时再次检查。

当前支持常规同站账号密码表单，以及使用 Cookie/localStorage/sessionStorage 的登录态。验证码、扫码、二次验证、跨域 SSO、必须通过 POST 读取内容的应用及自定义加密登录协议，不作为本轮自动登录已支持项；失败会明确提示使用本地已登录浏览器，不会自动重试密码。复杂页面可在高级设置中指定账号框、密码框和登录按钮。

## 验证

- Shared：9 项参数测试通过，拒绝非 HTTPS、跨源、外链、非隔离及未录制的登录任务。
- Server：43 项定向测试通过，覆盖网络限制、一次性提交、普通抓取兼容和真实 Chromium 登录录制。
- PostgreSQL：6 项审批/凭据测试通过；原有在线普通录屏测试因外网开关未开启跳过。验证加密存储、跨用户隔离、审批篡改、过期清理和并发消费。
- Chromium：受控登录站点实际提交测试账号、接收 Cookie、进入已登录页面，遮挡账号密码并生成非空 WebM，FFmpeg 完整解码。
- Web + PostgreSQL：确认前无作业，确认后完成录制，localStorage 中没有账号密码，服务端密文已清空，播放与刷新恢复成功。
- Shared、Server、Web 类型检查通过；候选 Web 从既有生产候选基线叠加本轮文件构建，避免带入其他未提交功能。

本轮测试凭据只属于受控测试站点。用户尚未提供具体业务网站的专用测试账号，因此不将测试站点成功等同于任意第三方网站兼容。生产与桌面验收结果在发布后追加。

证据目录：`.creative-test-results/website-login/`；日志 `website-login-tests-final.log`、`website-login-db.log`、`website-login-web-e2e-final.log`、`website-login-mask.log`。
