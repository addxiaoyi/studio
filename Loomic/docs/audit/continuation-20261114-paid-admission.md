# 2026-11-14 预扣后才允许执行

## 实现范围

图片/视频 HTTP 创建入口、视频同步生成入口、聊天 Agent 创建和 Agent 工作流创建现在把付费任务标为 `billing_required`。审批确认入口也显式设置该标记。数据库列默认 false，不推断历史任务的费用状态。

新的付费任务初始显示 `awaiting_credit_reservation`。队列读取与 Worker 原子领取共用门禁：预扣凭证必须属于同一用户、工作区和任务，交易类型为生成扣款，金额必须与原预扣匹配。仅有一个交易 ID 或仅已完成账本扣款都不能开始执行。关联预扣时同时保存冻结价格，完成后释放队列门禁。

免费任务不因此要求非零扣款；审批前缀的免费任务仍需真实消费的零费用审批。已完成费用结算后，检查原预扣金额而非更新后的最终金额，避免结果同步恢复被阻断。
