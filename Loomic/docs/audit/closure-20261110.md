# 2026-11-10 工作区修复与发布验收

基线为 `76d7d23`，范围包括信息流步骤恢复、私有媒体流式读取、Agent 浏览器轮询、试穿素材与保留状态、工作流预算，以及用户截图指出的导出弹窗适配。没有执行生产付费生成或自动批准用户的待确认任务。

## 实现

- 信息流将当前步骤与可继续的进度分开。URL 恢复独立读取内容包，不再等待热点和模型目录。新建包携带实际包 ID，过时详情响应不能覆盖后续选择；状态显示中文。
- 私有媒体先通过认证签发五分钟、HttpOnly、资源路径限定的播放 cookie，然后直接使用 Range 流式播放。每次文件请求仍核验权限、删除和到期；30 秒连接/缓冲超时可重试并保留播放位置。原文件下载先续期，使用独立下载通道，避免桌面主窗口跳转。
- 会话临时错误从约 2 秒开始指数退避，最多 60 秒，支持 Retry-After、请求 ID 和 HTTP 状态诊断。离线/隐藏暂停，恢复后刷新；401/403 停止自动重试。无活动会话且面板关闭时降至 30 秒。保留慢帧不中断与账号隔离回归。
- 原生试穿支持从当前账号素材库搜索、分页选择人物和服装。文件经权限验证后进入原有照片压缩/参考图处理管道，仍需逐次费用确认。结果卡读取服务端实际保留时间，区分删除、到期和无法核验；本机记录保留。
- 整次工作流运行保存预算上限，直接运行、节点局部运行和 AI 确认共用门禁。默认 0 禁止付费。数据库锁和审批触发器原子保留额度；并发超限只能通过预算内的确认，重复确认不重复占用，变更预算不能复用旧请求。运行历史显示上限、已确认和剩余额度。
- 导出弹窗补齐上游空的容器、图片格式、帧标签。使用站点主题、可滚动参数区；窄屏横向导航与上下排列参数，导出按钮可见，菜单不会被弹窗裁切。标签支持方向键、Home/End 和 Tab。

## 预算边界

上限约束累计确认金额，不因退款自动增加本次额度；它不替代最终账单。逐项审批仍保留。按实际 token 用量结算的模型不能保证硬上限，因此工作流会明确要求选择固定价格模型。分支只为实际确认的生成节点占用额度，固定结果不重复收费。旧运行仅回填已经批准的额度，不自动授权尚未确认的节点。
