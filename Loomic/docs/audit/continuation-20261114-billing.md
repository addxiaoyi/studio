# 2026-11-14 生成费用结算

## 本轮实现

- Worker 现在对按秒计费的视频使用供应商返回的实际 `duration_seconds` 结算，而不是始终采用请求时长。
- 结算会与已预扣积分计算差额：实际费用更高时补扣，更低时退款，最终把 `credits_cost` 更新为实际费用并沿用同一任务账单关联。
- 按 token 模型继续要求供应商返回输入和输出 token；固定按次模型不重复调整。
- 缺少实际 token 或供应商视频时长时，任务不会当作免费成功；对应错误进入不可盲重试路径。若已保存供应商结果，则保留结果等待人工/恢复流程核验，不自动退款。
- 通用 Job 取消接口对 `queued` 任务立即取消；对 `running` 任务在事务行锁内写入独立 `cancel_requested_at` 并保留运行状态。Worker 成功、等待画布回写和最终同步都会保留取消结果；完成回执记录 `completed_after_cancel_request`。请求和最终完成并发时由行锁序列化：请求先提交则完成回执保留标记，完成先提交则取消入口读到终态并拒绝。
- 取消请求后的重启恢复若没有供应商结果检查点，会停止自动重跑并标记 `cancel_outcome_unknown`，保留预扣积分等待人工核验；已有供应商检查点则继续完成结果同步。

## 边界
