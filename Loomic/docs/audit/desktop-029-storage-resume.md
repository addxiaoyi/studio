# 0.2.29 本地素材续扫与恢复

## 交付范围

- 重复扫描不再受 4 GiB 单次上限限制。4 MiB 分块内容摘要保存在账户独立的扫描记录，暂停和重启后复用；大小、inode、修改时间或创建状态变化会重新校验。分块摘要只用于重复比较，不替代上传回执的 SHA-256。
- 保留 25000 文件、20 层目录的枚举边界并显示未覆盖提示。扫描不会删除原片；清除进度只删除扫描记录。
- 整目录匹配按格式、大小和 SHA-256 校验，预览无写入。每项由用户选择候选，确认后再次验证文件和索引；外部原文件复制到工作区并保留来源。结果逐项返回，失败可重新核对。
- 封面容量按工作区配置，0 为关闭，16–1024 MiB 为启用。降低容量立即淘汰最久未使用封面，保留 1000 张和 30 天限制。界面显示清理原因、时间和数量；检查在读取/生成封面及打开设置时发生。
- 在线桌面设置与离线快照均接入操作；不需要服务器新增存储，不涉及数据库迁移。

- `e2e/storage-resume.mjs` 接入 Windows 与 macOS/Linux 安装包 CI，只上传报告和截图，不上传大文件夹具。
- 独立 Linux 升级回归使用公开的真实 0.2.27/0.2.28 AppImage，先校验完整文件摘要，再通过旧版更新器替换。固定测试更新源只用于锁定目标版本，恢复 API 使用隔离夹具，不冒充生产恢复。
