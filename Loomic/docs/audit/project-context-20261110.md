# 统一工程上下文阶段（候选实现）

本阶段推进全局目标 2 的身份、导航及恢复基础；不代表视频工程已支持跨设备同步或九项目标完成。

## 行为

- 同一工程的画布、工作流、时间线、视频和对话共用 projectId、canvasId、sessionId，合成使用独立 compositionId。服务端恢复当前账号的最近工程及视图；地址栏片段在编辑器改写 `?/Composition` 后仍保留工程身份。
- `project_user_contexts` 保存每用户/工程的最近视图与版本。所有读写核对工程所有权、归档状态、画布归属及对话所属；乐观版本冲突返回 409，不覆盖另一个窗口。相同窗口的合成变化与页面切换串行保存。
- 工程视图切换先等待画布/视频写入完成。视频 AI 或文字剪辑仍有未完成修改时阻止切换并说明原因。
- 老画布视频工程、AI 对话和方案事务性复制到新工程命名空间，原记录保留；默认本机独立草稿不自动迁入其他工程。迁移完成、编辑器就绪后才挂载对话，防止空会话抢先覆盖旧草稿。
- 视频导出关联当前画布，工程模式只展示相应画布的本机导出。
- 第二个设备没有视频本机副本时明确说明，保留打开当前画布和对话的入口，不创建替代空白视频工程。视频文档与媒体跨设备取回仍待后续完成。
- 沿用现有菜单/主题组件；窄屏使用下拉选择，Tab/Enter/Escape 可操作。窄屏积分入口移入布局流，避免遮住视频标题。

## 已执行验证

- 新数据库回归先以缺少路由失败，再补实现：跨账号/跨工程拒绝、对话归属、归档、并发版本冲突、最近位置恢复通过。真实本机 PostgreSQL，隔离 schema 在结束后删除。
- 前端定向测试 11 项通过：身份链接、旧入口兼容、独立草稿恢复、首次位置持久化、不可访问上下文、保存失败阻止导航、串行更新、启动状态。
- 真实 Chromium：旧画布源代码和对话草稿迁移、独立草稿保留、视频刷新、返回原画布、第二浏览器上下文恢复工程归属、缺少视频副本反馈、菜单键盘操作通过。
- 窄屏为 638px 视口加 CSS zoom=2（约 319px 内容宽度），暗色主题、菜单焦点恢复和横向溢出检查通过。这不是桌面系统高 DPI 或辅助技术读屏验收。
- Shared 构建、Server/Web/Desktop 类型检查与编辑器运行时构建执行记录位于 `M:/loomic-builds/project-context-*.log`。最终 CI 结果另记，不以本地检查代替。
