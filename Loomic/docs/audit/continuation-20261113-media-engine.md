# 2026-11-13 媒体预览引擎续作

## 本轮实现

- 普通画布导入视频时只通过私有播放授权读取 `metadata`，不再先把整段视频下载到浏览器内存；图片仍在用户确认导入后读取原文件。
- 桌面导出超过 64 MiB 时生成同目录低分辨率代理：854px 宽、H.264 CRF 30、AAC 96 kbps。原片路径和设备/大小/修改时间指纹仍保留，预览 IPC 读取代理文件，交付仍使用原片；生成前检查素材盘可用空间并预留至少 512 MiB。
- FFmpeg 执行器解析 `-progress pipe:2` 的机器事件，代理生成日志按编码秒数输出进度，后续桌面任务/界面可复用同一事件源。
- 桌面 preload 暴露 `onVideoPreviewProgress` 和取消接口，代理开始、运行、完成和失败状态通过 IPC 传到渲染层；视频 AI 编辑面板和聊天方案面板显示阶段、已编码秒数及失败原因，并可中止当前代理 FFmpeg 进程。
- Web AI 视频工作流回归覆盖进度文本和取消按钮，避免 IPC 事件只在桌面主进程可见。
- 代理文件只允许位于当前本地素材目录，历史记录重启后重新校验；代理生成失败或历史写入失败会清理临时代理，避免系统盘积累孤儿文件。

## 2026-11-14 长片代理压力补充

- 使用本机可运行的 FFmpeg/FFprobe 生成 4K、12fps、600 秒的隔离测试源，源文件约 610 MiB；该二进制仅用于压力验证，不作为桌面发布资源。
- 压力过程中发现原代理滤镜在某些宽高比下会输出奇数宽度（实际出现 853x480），H.264 拒绝打开编码器并留下空文件。
- 已将代理滤镜改为缩放后补齐偶数尺寸：`scale=854:-2:force_original_aspect_ratio=decrease,pad=ceil(iw/2)*2:ceil(ih/2)*2`，并新增回归测试。
- 修复后完整 600 秒源代理编码成功，运行约 12.7 秒，约 49x 实时速度；输出约 10.8 MiB。
- FFprobe 验证输出为 H.264、854x480、YUV420P、600 秒；输出可读取且没有空文件。
- 专用压力源和代理文件已在验证后删除。
