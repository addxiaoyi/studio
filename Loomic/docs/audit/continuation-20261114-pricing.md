# 2026-11-14 审批价格快照

新增 `generation_approvals.billing_pricing`。报价创建时将计费类型和单价与审批一次写入；按秒单价由用户看到的总报价除以请求秒数得到，保留分辨率差异。按 token 模型保存输入/输出单价。配置模型使用对应的供应商模型计费配置作为来源。

`20261114000002_approval_pricing.sql` 添加快照列和不可变触发器。历史审批保持空值，不能用当前价格伪装成历史价格。Worker 对存在审批但没有有效快照的记录报出待核验错误，保留结果和预扣。

结算读取已消费、同一任务/账户/工作区的审批快照。事务内重新核对审批额度，实际金额超出该额度时不修改余额或账本，返回 `generation_settlement_review_required`，供后续额外费用审批使用。

验证：真实 PostgreSQL 回归将供应商单价从 0.3 改到 9，已有审批仍按 0.3 结算；快照改写被数据库拒绝；实际金额超过确认额度时余额和账本不变；重复结算返回原凭证。审批、账本和用量计算测试合计 41 项通过，其中数据库测试 21 项。两份新增结算/报价迁移均重复执行验证。

边界：额外费用再次审批的前端入口尚未完成；超额任务当前保留为待核验。没有审批记录的历史任务仍遵循原兼容分支，自动审批流程也尚未统一保存价格快照。供应商原始账单核验和生产部署均未完成。
