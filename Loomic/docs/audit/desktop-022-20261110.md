# Desktop 0.2.22

## Changes

- Package only compiled application files and the native module for the target OS. Remove duplicated browser OCR cores, source maps and bundled React runtime copies. Keep all six Node OCR cores, native automation libraries and React license notices.
- Ship identical FFmpeg/x264 source tar contents compressed with XZ; verify binary/source SHA-256 checksums before and after packaging. Keep license and configure files.
- Chinese/English assisted installation, current-user default, selectable installation folder and an explicit data-retention explanation. Setup and uninstall wait for the running app to exit; silent installation returns 1618 instead of force-killing active work.
- Local recovery screen for connection failure, a 25-second navigation timeout and renderer crashes. Retry restores the requested route; the system-browser and workspace-home actions remain available offline.
- Persist and clamp window bounds to connected monitors, restore a minimized/hidden window from the tray or a second launch, use the packaged tray icon, and allow actual macOS quitting.
- Guard exit/update installation while recording, exporting, uploading or running Agent tasks. Keep per-action approval unchanged.

## Reproduction and delivery boundaries

Run `pnpm --filter @helstera/desktop typecheck`, `pnpm --filter @helstera/desktop test`, and `node --test apps/desktop/scripts/verify-video-resources.test.mjs`. Build pinned Windows media tools with `scripts/build-windows-video-tools.sh`, then build the desktop candidate. `afterPack` rejects missing runtime files, wrong-platform native binaries and development files in the archive.

Set `HELT_DESKTOP_EXE` to the packaged executable and `HELT_DESKTOP_LIFECYCLE_DIR` to a new test directory, then run `node apps/desktop/e2e/lifecycle.mjs`. The test uses a loopback server and an isolated profile. The Windows CI job runs it after packaging.

Local evidence is in `M:/loomic-builds/desktop-022-*`. macOS/Linux real installation and code signing are not covered by this Windows acceptance; the current build has no signing certificate.
