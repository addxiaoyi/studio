## 用户流程

- 设置 → 本地工作区与云端副本 → 从本地快照恢复工程。原生文件选择器读取 Projects 中的 JSON，显示元素、会话、消息、待上传素材数量和大小。明确勾选并确认后才上传素材、创建新画布；原工程保留。
- 已完成恢复返回“打开恢复的画布”，自动定位恢复内容。重复恢复同一快照不会重复创建工程；历史工具操作转为历史记录，不重新执行或触发模型费用。
- 保存媒体时显示速度、预计剩余时间与已续传大小。暂停或断线留下经过校验的片段；继续时通过 Range / If-Range 校验原文件版本。文件版本变化则完整重下，偏移或内容不匹配不得发布为完整文件。
- 0.2.23 的本地目录、账户分区、设置与原文件继续兼容；云端数据过期不会删除本地副本。恢复需要登录到快照所属账户，且不代表完整离线编辑器。

## 校验与限制

快照最大 16 MiB、20,000 元素、100 个会话，每会话最多 5,000 条消息。预览绑定当前账户、快照哈希和本地素材哈希，30 分钟有效；缺失且云端不可用的素材阻止恢复。素材恢复复用当前私有上传接口：图片最多 25 MiB，视频最多 250 MiB；支持 PNG/JPEG/WebP/MP4/WebM。媒体下载单文件最多 2 GiB，预留 64 MiB 磁盘空间。

恢复由 PostgreSQL 事务和按快照派生的幂等 ID 保证一致性；并发恢复、消息插入故障回滚、越权素材拒绝均有真实 PostgreSQL 回归。无需数据库迁移。下载检查点只保存文件校验信息，不保存会话令牌、Cookie 或下载 URL。
