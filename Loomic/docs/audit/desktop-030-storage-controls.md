# 0.2.30 本地扫描与重复素材合并

## 功能

- 重复扫描默认 32 MiB/s，可在在线桌面设置和离线快照库调整为 8/16/32/64/128 MiB/s 或不限速。逐块等待可被暂停中断，长时间空闲不积累突发读取额度。
- 扫描记录同时保存到本机配置目录。工作区磁盘断开或原路径出现另一块磁盘时停止，保留进度；原盘重新连接后由用户继续。文件仍按大小、文件身份和修改时间校验，改变的文件重新读取。
- 目录匹配预览与逐项选择保留 7 天，重启后恢复到待确认状态。确认仍检查当前账户、工作区、索引和原文件内容，保存预览不会执行关联。
- 重复素材合并先核对当前账户的画布快照、素材索引、恢复记录和本地视频工程。用户选择共享原文件和副本后再次确认；通过文件系统硬链接共享内容，原路径和素材 ID 保留。直接修改共享原文件会影响所有引用，界面明确说明。
- 合并限定同一工作区账户素材，保留导出成片独立管理。内容、权限不同或文件系统不支持硬链接时保留副本并报错；预览期间工程/素材变化会阻止执行。每个文件原子替换，失败逐项显示，已存在的路径继续有效。

## 当前验证

- Desktop：55 个测试文件、196 项通过；9 项依平台或原生环境条件跳过。新增限速、断盘镜像进度、预览重启、确认合并及文件变化回归。
- Windows 实际程序已验证预览和选择重启恢复、未确认不执行、8 MiB/s 读取约 16 MiB 用时 2111 ms、两个工程引用核对、合并后原路径和 ID 保留、视频正常播放，本地操作云端请求为 0。
- 全平台原生回归新增 `storage-controls.mjs`。Linux 另以专用虚拟块设备实际卸载/挂载文件系统，测试磁盘中断、进程重启和续扫；这是隔离卷断连测试，不声称完成物理 USB 线缆拔插。
