# 2026-11-14 自动审批价格快照

## 实现

- `recordGenerationReservation` 在任务行锁内关联预扣交易、金额和 `billing_pricing`。优先复用原审批快照；自动审批读取当次配置，再使用内置价格作为兼容后备。
- 按秒单价从预扣金额和请求秒数计算，保留分辨率报价；按 token 保存输入与输出费率，按次保存固定金额。
- 已存在的快照不随调价改变；重复关联同一交易可以重放，另一笔交易或不同金额不能覆盖原预扣。已结算任务不会被迟到的预扣回执回退。
- 增量迁移 `20261114000004_reservation_pricing.sql` 增加任务价格快照并阻止非空快照被改写；已加入候选包门禁。
- 结算优先读取原审批价格，其次读取自动预扣快照，不再为这些任务读取新价格。

## 验证

- 数据库配置按次收费而内置目录按秒收费时，显式与自动审批均保存数据库中的按次计费方式。
