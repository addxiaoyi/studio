## 提示词 API

从 `local-growth.ts` 提取三条提示词路由至 `http/prompt-catalog.ts`，保留公开读取与认证后浏览/收藏的 API 契约。

- 分页拒绝 NaN、Infinity、非整数、负数、重复参数及超出上限的参数，避免异常值进入 SQL。
- 每次取 `limit + 1` 行决定是否还有下一页，只返回所请求的页；增加唯一 id 排序打破相同排名/时间的平局。
- 浏览/收藏校验 UUID，未发布、已删除和缺失提示词返回 404，不创建收藏或泄露私有条目。
- 收藏先锁定仍发布的提示词，在同一事务内切换收藏与重算计数。12 个并发请求的最终收藏及计数一致；计数失败时整个事务回滚。
- 内部数据库错误不暴露诊断，返回固定可重试文案；Fastify 非法 JSON、超限及不支持类型仍保留 400/413/415，不能改成 500。

原实现的 15 项接口回归全部失败，修复后通过。真实 PostgreSQL 检查包含稳定分页、隐私边界、并发和故障回滚；内部诊断暴露另有一次失败后修复证据。
