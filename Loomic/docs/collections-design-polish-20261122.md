# 项目列表与资产页细节优化

继续使用 UI UX Pro Max 的网页层次、空状态及筛选集合重排建议，延续首页的字体、边距、边框和卡片信息层次。本轮为本地源代码修改。

- 项目列表将新建入口移到标题工具栏，与搜索并排；实际项目使用一致网格，名称两行展示，来源、创建和更新信息分开排版。
- 降低预览占位的装饰强度，保留真实缩略图与不可用状态；键盘焦点和触屏删除入口仍可达。
- 资产页统一标题、搜索、恢复区和类型筛选工具栏；当前类型通过文字粗细、背景及 `aria-pressed` 表达。
- 资产卡片对齐名称、时间、保留期、下载和公开状态；移除底部装饰模糊，保留原有预览、权限和动作逻辑。
- 空状态区分“没有资产”“没有搜索结果”和“恢复区为空”，提供清除筛选、返回资产列表或创作页入口。
- 加载骨架与新的网格断点对齐；320px 下重排成单列，搜索字号为 16px，主要触控动作扩大。

## 验证

项目、来源标签、缩略图和旧资产请求隔离组件回归 15 项通过。新增本地 Chromium 场景覆盖 1440 / 768 / 320px、项目搜索与清除、图片/视频筛选、选择、无结果与恢复区切换，并生成深色资产页截图。预览使用仓库自带展示图及本地测试记录，没有访问生产资产或执行公开/删除操作。

类型检查和 `git diff --check` 通过。浏览器命令：设置本地 `DATABASE_URL` 后执行 `pnpm --filter @helstera/web exec playwright test --config playwright.workflow.config.ts collections-design.spec.ts`。
