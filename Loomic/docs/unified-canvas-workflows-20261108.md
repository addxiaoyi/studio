# 普通画布与工作流共用一个场景

参考 `Stonewuu/ai-fusion-video` 的统一无限画布、素材输入、节点属性和助手预览交互。参考提交固定为 `308cd8f5484162a990111f37696940e02afb648e`，许可证为MIT，出处记入 `THIRD_PARTY_LICENSES.md`。

## 使用方式

原画布左侧“工作流”打开右侧流程面板。节点直接成为原 Excalidraw 场景中的元素，不再打开独立 React Flow 编辑器。画布只有一套移动、缩放、选择、箭头、分组和保存路径；收起面板后仍能看到节点和结果。窄屏使用底部面板，保留上部画布。

- 原有图片、录像、文字与手绘图形保留；节点可在同一画布移动，使用箭头工具A连接，也可在节点属性中通过键盘选择上游。
- 支持网址、搜索、浏览录制、裁剪、输出、画布素材六种节点。新增节点会尝试连接所选的兼容上游。无效连接不会进入可执行计划。
- 已上传图片或视频可通过“使用所选素材”变成输入；从现有视频向裁剪节点绘制箭头也会建立输入关系。原媒体保留在原位置，不复制成第二份素材。
- 执行状态在节点上显示，侧栏包含参数、AI搭建、运行历史和审批；输出素材使用虚线关联原输出节点，可定位到画布结果。
- AI方案先预览、再应用成草稿，执行绑定保存版本。执行前同步保存原画布；裁剪、录制继续逐项审批。图形只是流程的可视表示，不能绕过服务器执行校验。
- 本地草稿恢复、并发版本检查、运行日志和已完成步骤不自动重放仍保留。复制节点使用独立标识，避免副本编辑影响原节点。

## 数据与权限

工作流仍保存在 `canvas_workflows`，不可变运行快照在 `canvas_workflow_runs`；节点与箭头同时映射到画布元素的 `customData`。只同步当前流程对应的元素，不替换整张画布。旧流程首次打开会放在已有内容旁边，避免清空旧内容。

`canvas.asset` 在运行前、实际执行及后续检查点验证画布成员、素材所有者、原元素绑定、媒体类型、删除和保留期限。私有素材没有被转成公共URL。图片可作为输出引用；视频可进入现有FFmpeg裁剪执行器。

联合测试暴露了后台截图与自动保存的竞争：后台写入之后，较早读取的画布保存可能覆盖新截图。保存SQL现在在原有版本CAS条件下合并新到达的后台结果和对应文件。客户端保存显式删除标记，防止用户删除的素材被重新合并。
