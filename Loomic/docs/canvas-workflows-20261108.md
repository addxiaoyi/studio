# 画布可视化工作流

后续已改为与普通画布共用原生场景，参见 [统一画布工作流](./unified-canvas-workflows-20261108.md)。下文保留首次独立编辑器版本的验收记录。

画布左侧工具栏新增工作流入口。流程包含可编辑节点、类型约束连线、拖动布局、自动排列、撤销重做、缩放、小地图和参数面板。支持网址输入、网页搜索、浏览/录制、录像裁剪、输出到画布五种节点。每个处理节点都必须连接到唯一输出节点，保存不完整草稿可以，执行时拒绝缺失参数、孤立节点、不兼容输入、重复连接和循环。

AI面板调用现有真实目标规划模型，仅返回结构化计划，转换成节点后先预览再应用。主聊天Agent新增 `inspect_canvas_workflows` 和 `draft_canvas_workflow` 工具，可以读取当前流程或创建/修改草稿；工具不能启动运行。编辑现有流程须携带精确版本。

工作流和运行快照保存在新增 `canvas_workflows`、`canvas_workflow_runs` 表。执行编译到现有V2目标步骤日志，复用动作指纹、一次性审批、暂停/继续、结果不确定时人工核验。运行前用户确认保存版本，录制/剪辑步骤仍需单独批准。重复运行请求复用原目标，运行中不能修改其草稿；新版本保留历史运行记录。

权限校验包含画布工作区成员、创建者、会话与画布归属，并在执行检查点复查撤权。结果写回修复了旧路径把asset_objects ID当作generated_assets ID的问题，过期/删除素材会阻止交付，避免空结果冒充完成。结果回到当前画布及关联聊天。
