# 对话式网站体验、登录接管与剪辑衔接

默认侧栏改为填写网址和体验目标。当前工作区 Agent 模型读取公开页面导航，返回有顺序的路线；用户可继续输入修改要求，确认后才创建录制作业。手动参数保留为折叠入口。账号登录会识别常规登录入口、密码模式及登录结果，成功标记和 CSS 选择器均为可选项。

遇到验证或用户选择手动登录时，任务保持同一编号并进入 `waiting_login`。侧栏显示未录制的真实登录画面，用户可点击、拖动、输入、按键和滚动；完成后明确继续。命令绑定用户、工作区、页面与帧，输入加密排队，执行前清空密文，一次性消费，回执不确定时不自动重试。刷新后恢复同一接管会话。登录结束删除临时验证画面。

可选记住登录态 24 小时。Cookie、localStorage 和 sessionStorage 加密存储，并绑定用户、工作区与网站来源；支持清除和到期失效。保存的是会话，密码仍只供本次任务使用。重新使用失效会话时明确报错。仅支持网页内的验证码/扫码；跨站 SSO、原生硬件验证和依赖不支持浏览器通道的网站不保证兼容。

路线按真实导航唯一匹配执行，无法找到或出现歧义时停止，不猜坐标。副作用入口及跨站页面被拦截。完成录像可一键进入视频工作区，私有下载、实际素材登记和刷新去重均有检查；导入失败提供重试，原工程保持可继续编辑。
