# Inspire-Studio 的创作复用设计

参考仓库 `xc-2000/Inspire-Studio`，固定提交 `3ce81a3ee826a9ff70a115093411eee01077e35e`。本轮参考了工作流库、提示词选择、显式画布引用、结果对比的产品设计，落实到现有画布和节点协议。

源码证据：`web/src/features/canvas/components/canvas-workflow-library.tsx`、`canvas-prompt-picker.tsx`、`canvas-video-compare.tsx`、`utils/canvas-resource-references.ts`、`components/canvas-agent-composer.tsx`。README标注MIT而LICENSE为AGPL-3.0，存在不一致；本轮独立实现，未复制源代码、素材、字体或打包应用，出处记入第三方说明。

## 接入的四项能力

1. **个人模板库**：在画布流程侧栏“资源库”保存完整流程或所选节点，保留参数、文字和内部连线。模板在同一工作区的不同画布可复用，默认只对创建者可见。插入创建独立节点标识，不创建运行。移除是可撤销的归档。
2. **提示词库**：内置电影自然光、商品展示、角色一致性、可拍摄分镜、竖屏短片5组创作方向。支持追加或替换当前AI输入/文字节点/编剧要求/生成提示词，保存自定义提示词后可搜索、复用、移除和撤销。
3. **AI画布引用**：先选中普通画布文字或已保存图片/视频，再点击AI面板“引用画布选区”。引用逐项可见、可移除。请求仅传元素ID，服务端从当前有权限的已保存画布解析原文与素材标识；删除或无权访问的引用被拒绝。方案仍需预览确认。
4. **历史结果对比与复用**：在运行记录中打开左右两列对比，查看不可变运行版本、实际参数、正文、图片和视频。已完成文字可作为新提示节点；有效素材可作为当前画布输入，复用不会新建生成任务或扣费。素材到期、删除或权限撤销后禁止复用。

## 数据与兼容

- 新增迁移 `20261108000005_creative_library.sql`，创建个人库表及索引，不修改已有业务数据。
- 模板存储前在服务端强制清除私有素材ID和原元素ID，导入后显示素材槽，用户从目标画布选择并绑定。未绑定素材会阻止执行。
- 仍使用既有工作流保存、一次性生成费用确认、执行日志、画布自动保存与冲突处理。复用结果不会静默重新运行任何节点。
- 图像重新插入时读取真实尺寸和原MIME类型；原画布已有素材优先复用同一个元素。
